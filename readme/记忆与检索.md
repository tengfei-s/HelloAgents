### 记忆类型层

#### WorkingMemory

##### retrieve(query)

```
retrieve(query) 检索记忆的完整运行逻辑

1. 输入查询内容

用户输入一个 query，例如：

query = "用户喜欢什么编程语言"

retrieve() 的目标是：

从 self.memories 中找出和 query 最相关的几条记忆。

---

2. 清理过期记忆

首先执行：

self._expire_old_memories()

作用是删除超过 TTL 的工作记忆。

例如工作记忆只保留 120 分钟，那么超过 120 分钟的记忆不会再参与检索。

---

3. 判断是否还有记忆

如果：

self.memories 为空

直接返回：

[]

说明当前没有可检索的记忆。

---

4. 过滤被遗忘的记忆

遍历 self.memories，只保留没有被标记为 forgotten 的记忆。

判断条件是：

m.metadata.get("forgotten", False)

如果某条记忆是：

metadata = {"forgotten": True}

那么这条记忆会被跳过。

过滤后得到：

active_memories

---

5. 按用户 ID 过滤

如果传入了 user_id，就只保留该用户的记忆。

例如：

user_id = "user_001"

那么只检索 user_001 的记忆。

注意：

如果 MemoryItem 里没有 user_id 字段，应该从 metadata 中取：

m.metadata.get("user_id") == user_id

过滤后得到：

filtered_memories

---

6. 如果过滤后没有记忆，直接返回

如果：

filtered_memories 为空

说明没有符合条件的记忆，直接返回：

[]

---

7. 尝试使用 TF-IDF 计算语义相似度

先把 query 和候选记忆内容组成 documents：

documents = [query] + [m.content for m in filtered_memories]

其中：

documents[0] 是 query
documents[1:] 是记忆内容

然后使用 TfidfVectorizer 把文本转换成 TF-IDF 向量。

再使用 cosine_similarity 计算：

query 向量 和 每条记忆向量 的相似度。

得到的结果保存到：

vector_scores

形式类似：

{
    "memory_id_1": 0.65,
    "memory_id_2": 0.21,
    "memory_id_3": 0.0
}

分数越高，说明这条记忆和 query 越相似。

---

8. 如果 TF-IDF 失败，就回退到关键词匹配

如果 sklearn 没安装，或者向量化失败，vector_scores 会变成空字典：

vector_scores = {}

后面就只依赖关键词匹配分数。

---

9. 遍历每一条候选记忆并计算分数

对 filtered_memories 中的每条 memory，都计算一个 final_score。

---

10. 获取 TF-IDF 分数

对于当前 memory，先从 vector_scores 中取分数：

vector_score = vector_scores.get(memory.id, 0.0)

如果 TF-IDF 成功，就得到相似度分数。

如果失败或没有匹配，就是 0.0。

---

11. 计算关键词匹配分数

先把 query 和 content 都转成小写：

query_lower = query.lower()
content_lower = memory.content.lower()

如果 query 完整出现在 content 中：

keyword_score = len(query_lower) / len(content_lower)

如果 query 没有完整出现在 content 中，就按空格分词：

query_words = set(query_lower.split())
content_words = set(content_lower.split())

然后计算共同词：

intersection = query_words.intersection(content_words)

如果有共同词：

keyword_score = len(intersection) / len(query_words.union(content_words)) * 0.8

这个分数越高，说明 query 和 memory 共享的关键词越多。

---

12. 混合 TF-IDF 分数和关键词分数

如果 vector_score > 0：

base_relevance = vector_score * 0.7 + keyword_score * 0.3

意思是：

70% 依赖 TF-IDF 相似度
30% 依赖关键词匹配

如果 vector_score == 0：

base_relevance = keyword_score

也就是只使用关键词匹配分数。

---

13. 加入时间衰减

计算当前记忆的时间衰减：

time_decay = self._calculate_time_decay(memory.timestamp)

越新的记忆，time_decay 越接近 1。

越旧的记忆，time_decay 越小。

然后：

base_relevance *= time_decay

这样旧记忆的分数会被降低。

---

14. 加入重要性权重

计算重要性权重：

importance_weight = 0.8 + memory.importance * 0.4

如果：

importance = 0      → weight = 0.8
importance = 0.5    → weight = 1.0
importance = 1.0    → weight = 1.2

然后得到最终分数：

final_score = base_relevance * importance_weight

最终分数由三部分决定：

文本相关性
时间新旧
记忆重要性

---

15. 保存有效结果

如果：

final_score > 0

说明这条记忆和 query 有关系。

就保存：

scored_memories.append((final_score, memory))

---

16. 按最终分数排序

所有候选记忆打完分后，执行：

scored_memories.sort(key=lambda x: x[0], reverse=True)

按照 final_score 从高到低排序。

分数最高的记忆排在最前面。

---

17. 返回前 limit 条记忆

最后返回：

[memory for _, memory in scored_memories[:limit]]

也就是只返回记忆对象，不返回分数。

如果 limit = 5，就返回最相关的前 5 条。

---

总结：

retrieve() 的作用是：

根据 query 从工作记忆中检索最相关的记忆。

它的核心公式是：

最终分数 =
文本相关性 × 时间衰减 × 重要性权重

其中：

文本相关性 =
TF-IDF 相似度 × 0.7 + 关键词匹配 × 0.3

最后按照最终分数从高到低排序，返回前 limit 条记忆。
```
